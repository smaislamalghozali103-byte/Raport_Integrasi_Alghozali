# Logo resmi YPI Al-Ghozali

Letakkan file logo resmi yang diberikan pada percakapan ini di folder ini dengan nama:

- `logo-alghozali.jpg`

Aplikasi `app.py` otomatis membaca logo dari `assets/logo-alghozali.jpg`.

Jika file tidak ditemukan, aplikasi menggunakan fallback visual agar tetap dapat dijalankan.
